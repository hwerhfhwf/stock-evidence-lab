# FinScope 产品交付说明

## 用户任务

用户先确认公司做什么、收入来自哪里，再沿“经营与盈利 → 财务与现金 → 估值与预期 → 市场表现 → 事件与风险”深入。页面不要求先读使用说明，也不把不同层级压成一排同尺寸卡片。

首屏承担四件事：

1. 行情条确认公司、代码、最新价和数据时间；
2. 宽幅公司与业务区建立经营语境；
3. 收入构成环形图显示分部占比和金额；
4. 经营主图把收入与归母利润放在同一报告期比较，关键指标只补充图表无法直接表达的关系。

## 信息边界

- **客观事实**：直接来自扶摇或公司披露的金额、比率、价格和事件日期。
- **分析推断**：只解释已有事实之间的关系，不把原因猜测写成定论。
- **暂无法验证**：数据缺失、接口失败、口径不一致或 iFinD 未配置时的明确状态。

图表和结论旁的“查看依据 / 数据与出处”打开对应模块或披露证据，不显示无关报告目录。收入构成来自年报；前复权价格、收益和最大回撤来自扶摇历史 K 线。

## 交互

- 搜索名称或代码后调用实时研究接口；空搜索不发请求。
- 换股后公司概况、全部图表、估值、行情、报告时间线、证据和模型草稿一起重建。
- 简明 / 专业只改变展示深度，不改变事实。
- 证据抽屉支持 Esc 关闭并把焦点还给原按钮。
- 移动端改为单列；关键操作最小高度 44px；正文不小于 12px。
- OpenAI 兼容模型只增加受约束的研究草稿；先预览、后应用并支持撤销。

## 部署

构建和校验：

```powershell
npm test
npm run build
```

Sites Worker 运行时需要 `FUYAO_API_KEY`。iFinD 属于可选服务端增强；没有账户侧 MCP 配置时保持不可用状态。部署产物由 `scripts/build-worker.mjs` 生成，`ui/` 是前端权威源，`worker/` 是服务端权威源。

发布后验收：

- `/api/health` 返回扶摇密钥已配置；
- `/api/research?thscode=002594.SZ&name=比亚迪` 返回行情、财务、指标和估值模块状态；
- 首屏显示实时来源标签，收入构成仍明确标为公开披露；
- 搜索其他 A 股时不复用比亚迪分部收入；
- 任何缺失值都显示“暂无数据”，不补零。
