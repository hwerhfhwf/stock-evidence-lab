# 一分钟公司体检设计

## 意图

把按数据模块排列的分析师工作台，改成普通投资者一眼能理解的公司体检工具。用户搜索公司后，沿一条连续主线回答：整体如何、为什么、要警惕什么、下一步看什么。

## 目标

- 首屏十秒内说清产品用途和当前公司的总体状态。
- 一分钟内完成“赚钱能力 → 赚钱质量 → 财务安全 → 市场表现 → 信息缺口”的连续阅读。
- 专业指标先用人话解释，再提供原名、数值、口径和请求追踪。
- 每一步都回答“为什么要看、这家公司怎样、怎么理解”。

## 非目标

- 不输出综合分、买卖建议、目标价或确定性预测。
- 不把缺少的估值、同行和新闻证据补造成结论。
- 不删除原始财务表、走势图和数据血缘，但将其放到解释之后的证据层。

## 反目标

- 不继续使用行情、财务、血缘四个平级标签让用户自行拼接。
- 不把英文指标 ID 直接作为面向用户的标题。
- 不用大量相同权重的卡片制造“流水账”。

## 选定方案

采用“体检报告”单页叙事：顶部搜索；紧接一句总体判断和关键提醒；中部是五步垂直体检路线，每步包含通俗问题、意义、结论和一项核心证据；底部是下一步行动。走势图、财务表和数据血缘作为每步可展开的证据详情。

考虑过但放弃：保留标签页仅加新手提示，仍会割裂逻辑；聊天问答式入口学习成本低，但无法保证一分钟获得系统全貌。

## 内容结构

1. “一分钟看懂这家公司”搜索入口。
2. 公司体检摘要：一句结论、已确认/需留意/待补充数量、最重要提醒。
3. 五步体检路线：每一步的编号和连接线形成系统感。
4. “接下来做什么”：列出最值得核实的 2–3 项，而非泛泛建议。
5. “查看专业证据”：走势、三表、指标字典、请求追踪。

## 交互规则

- 默认展示完整体检主线，不需要理解导航。
- 点击“为什么看这个”显示一句入门解释。
- 点击核心证据展开对应专业证据，不离开主线。
- 状态只用“表现较稳 / 需要留意 / 出现分化 / 暂无结论”，颜色只是辅助。
- 指标名称采用中文解释名，英文 API 字段只在证据详情出现。

## 约束

保留现有扶摇服务端接口、模块级降级、私有站点权限和服务端 Secret。使用现有无框架 HTML/CSS/JS，不增加运行时依赖。
