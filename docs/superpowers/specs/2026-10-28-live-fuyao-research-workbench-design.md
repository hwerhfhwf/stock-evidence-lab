# Live Fuyao Research Workbench 设计说明

## 意图

把现有美的集团静态证据快照升级为真实适用于客户的多标的研究工作台。用户可以搜索任意 A 股，查看实时行情、约 250 个交易日的前复权历史、最近八期三表、最新财务指标，并沿每个诊断结论回到数据字段、报告期、行情区间和请求追踪信息。

## 目标

- API Key 只存在服务端运行时环境，浏览器和源码永不接触。
- 支持名称、代码或 thscode 搜索并消歧，不猜交易所。
- 服务端并发聚合行情快照、历史 K 线、三张财务报表和财务指标。
- 本地确定性计算 MA20/60/120、区间收益、最大回撤、现金覆盖、增长与杠杆矛盾。
- 每个结论标注 fact / inference / unknown 与来源、时点、口径、请求 ID。
- 接口权限不足、超时、缺失和部分失败均显式降级；允许已有模块继续展示。

## 非目标与反目标

- 不输出确定性涨跌预测、目标价、买卖建议或收益承诺。
- 不把上游 `null` 转成 0。
- 不把累计财务值当作单季值。
- 不把接口当前未开放的新闻、资金流或高频能力伪装成已接入。
- 不在浏览器、源码、日志、部署包或错误消息中返回 API Key。

## 架构

采用 Cloudflare Worker ESM：同一 Worker 服务页面和 `/api/*`。`FUYAO_API_KEY` 由 Sites 运行时密钥注入。API 网关采用允许列表，校验 A 股代码与查询范围，检查 HTTP 与业务信封 `code`，并将上游错误规范化。前端只调用同源网关。

## 核心链路

1. `/api/search?q=` 调用 `/api/meta/tickers/search`，返回受限的 A 股候选。
2. `/api/research?thscode=` 并发调用行情快照、前复权历史 K 线、三表和财务指标。
3. 服务端把长序列压缩为产品所需字段，并保留 request_id、timestamp、period_end_ms、currency 和数据状态。
4. 浏览器确定性引擎生成趋势、财务质量、估值缺失、行业缺失和事件缺失诊断。
5. 用户在行情、财务、证据、原始字段之间钻取。

## 失败模型

- `auth_missing`：服务器未配置 Key。
- `permission_denied`：上游 `code=2003`，只关闭对应模块。
- `upstream_timeout` / `upstream_error`：保留其余成功模块。
- `no_data`：明确显示空结果，不解释为正常。
- `stale`：响应时点超过阈值时显示快照年龄。

## 客户级边界

新闻公告原文、资金流和高频动向当前不属于公开能力，产品必须如实显示“数据源未开放”。生产化仍需要账户级额度、缓存策略、数据再分发许可和服务等级协议。
