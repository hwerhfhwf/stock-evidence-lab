# FinScope 实时公司研究工作台设计

## 目标

把现有静态比亚迪样例改造成可查询 A 股、可追溯数据来源、可局部降级的真实 Web 产品。页面帮助用户按“公司与业务 → 经营与盈利 → 财务与现金 → 估值与预期 → 市场与行业 → 事件与风险”理解公司，不输出简单好坏标签或买卖建议。

## 数据架构

- 扶摇是主数据源：公司检索、实时行情、前复权日 K、三张财务报表、财务指标和最新估值均从服务端接口取得。
- iFinD 是可选增强源：公告新闻、行业、宏观和政策信息只在服务端 MCP 配置可用时加载；不可用、超时或额度不足时仅对应模块降级。
- 浏览器永远不接触任何 API Key。所有密钥由部署平台环境变量保存。
- 比亚迪公开披露快照只作为网络失败时的明确标注后备，不冒充实时结果。
- 每个模块保留数据时间、来源和局部错误。缺失值显示为“暂无数据”，不补零、不推断。

## 页面结构

### 首屏

1. 顶部栏：股票搜索、简明/专业模式、数据更新时间。
2. 公司行情条：公司名、代码、行业标签、最新价、涨跌幅、成交额。
3. 公司与业务：深海军蓝宽幅视觉区，说明主营业务、研究口径和上市市场。
4. 收入构成：三类以内使用环形饼图，直接标注占比与金额，并提供文本列表。
5. 经营总览：最近八期收入、归母利润和经营现金的同口径趋势；相邻结论只解释图表无法直接表达的变化。

### 深入研究

- 经营与盈利：趋势图 + 利润桥，不把计算过程写成长句。
- 财务与现金：经营现金、资本开支、融资现金和流动性共同展示。
- 估值与预期：PE/PB/PS/PCF 最新值，明确口径和时间，不生成高低估结论。
- 市场与行业：价格/成交量/回撤主图；行业成分与同行估值作为可选增强。
- 事件与风险：iFinD 可用时显示与公司或行业直接相关的证据；否则显示具体缺失原因。

## 视觉系统

- 参考用户提供的同花顺风格图片：深海军蓝背景、局部青蓝高亮、宽幅公司视觉、紧凑但有呼吸感。
- 正文 14–16px；关键数字 20–30px；辅助信息不低于 12px。
- 首屏采用 12 栅格：公司业务 7 列、收入构成 5 列；经营主图 8 列、关键指标 4 列。
- 不再使用一组同尺寸卡片承载不同层级信息；大图承担主叙事，小指标只作补充。
- 图表采用可访问 SVG；颜色之外同时提供标签、数值和方向符号。

## 交互与状态

- 输入名称或代码，调用 `/api/search`，选择后调用 `/api/research`。
- 首次加载比亚迪实时数据；加载中使用稳定骨架，不移动布局。
- 扶摇失败时使用后备快照，并在公司行情条显示“公开披露快照”。
- 模块级 `ok / partial / unavailable` 状态分别显示实时数据、部分数据或具体缺失原因。
- 证据抽屉展示来源、期次、原值、请求追踪 ID 和必要口径。

## 验收标准

- 公开网页加载后真实请求扶摇；搜索不再固定返回比亚迪。
- 比亚迪页面展示实时价格、历史价格、财务指标和估值快照。
- 收入构成使用环形饼图，三类组成有直接标签和文本后备。
- 1440×900 首屏可看清公司业务、收入构成和经营主趋势；无关键文本小于 12px。
- iFinD 未配置时，其他模块仍可完整使用，页面不显示伪造资讯。
- 事实、推断、暂无法验证继续区分，并能沿具体数据查看依据。
