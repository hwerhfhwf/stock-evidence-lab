# 2026-10-28 公司体检工作台改版

目标：普通投资者先看到完整研究框架，再在每个检查项中连接数据、解释、边界与下一步。当前版本用规则化解读，不把规则输出冒充大模型分析。

## 设计与实现

七维固定导航；经营质量下固定增长协调性、盈利能力、现金兑现、运营效率。每个检查项合并事实和解释，证据覆盖仅按有数据的检查项计数。它不是公司好坏评分，也不代表这些问题已经得到完整解答。

中央区域用真实八期财务数据的同报告期柱图和约 400 个自然日范围的交易日行情折线。累计财报按同月份筛选，避免将半年和全年误当连续单季度。财务与行情时间戳按中国时区显示。负基数不计算普通增长率。

主页面展示人类可读计算，原始字段、请求编号、精度和计算输入保留在证据侧栏。移动端七维变为网格导航，保留完整检查框架。

## 当前真实边界

已经接通：搜索、财务三表、当前财务指标、历史行情。未接通：同日估值、可比同行、公告原文与事件兑现跟踪。通用框架不能替代银行、保险的专用指标体系。接口成功不代表所有数据都已由公告独立复核。180 天财务新鲜度是当前通用规则，尚未实现逐市场披露日历。

## 验证

自动化测试覆盖：旧模型与 API 合约、七维覆盖去重、实际字段映射、缺失不补零、负利润基数、历史数据过期、东八区期末日期。另执行真实接口与浏览器桌面/移动交互验收。最新通过数量以 TESTING.md 的交付记录为准。
