# Stock Evidence Lab

面向 A 股研究的可追溯多维诊断产品。系统结合公司类型和用户问题，从经营质量、财务趋势、估值、行情特征、行业位置、重要事件与风险中选择并排序相关维度。结果区分证据方向与认知状态，不输出综合评分、涨跌预测或买卖建议。

## 本地运行

需要 Node.js 18+ 与扶摇 API 密钥：

```powershell
$env:FUYAO_API_KEY = '仅在本地环境设置'
npm test
npm run build
npm run serve
```

打开 `http://127.0.0.1:4173/`。密钥只由服务端读取，不进入浏览器代码、构建产物或接口响应。

## 产品主链路

1. 搜索 A 股公司并输入研究问题。
2. 根据公司类型、问题相关性和数据可用性生成诊断范围与优先级。
3. 展示诊断摘要和前三个高相关维度的命题树。
4. 每个命题分别显示证据方向与认知状态。
5. 展开结论依据，查看原始字段、期次或行情区间、单位、来源、口径、计算过程与限制条件。
6. 使用待验证问题继续研究未接入或存在冲突的信息。

## 状态模型

- 证据方向：`positive | negative | conflicting | missing`。
- 认知状态：`fact | inference | unverified`。
- 两个字段相互独立；数据缺失不等同于负面证据。
- 客观事实与分析推断是不同命题对象，推断只能引用已经存在的事实证据。

## 代码结构

- `ui/diagnosis-model.js`：公司类型与问题路由、维度排序、命题、证据和计算对象。
- `ui/index.html`、`ui/app.js`、`ui/styles.css`：自适应诊断地图和命题级证据侧栏。
- `worker/research.js`：数据聚合与确定性行情计算。
- `worker/fuyao.js`：扶摇 API 适配、输入校验与错误归一化。
- `scripts/build-worker.mjs`：从唯一的 `ui/` 源生成 `dist/` 与 Worker 发布物。
- `tests/`：模型、追溯、接口、异常、合规、UI 与构建一致性契约。

## 数据边界

- 已接入：A 股搜索、行情快照、前复权日线、财务三表与五类财务指标。
- 未完整接入：同日估值、可比公司样本、公告与新闻原文。这些维度保留为 `missing + unverified`，并生成待验证问题。
- 半年度和季度财务数据按累计口径标注，不当作单季度数据。
- 未识别公司类型时使用 `general_corporate`，并在限制条件中明确显示，不根据公司名称静默推断行业。

## 合规边界

本产品仅用于研究辅助，不提供综合评分、目标价、收益承诺、确定性涨跌预测或直接买卖建议。
