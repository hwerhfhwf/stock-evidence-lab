# Stock Evidence Lab

面向普通投资者的一分钟公司体检。用户先提出一个具体问题，产品再给出一句话回答、对应因果链、反证与未知项，最后说明下一步该查什么。服务端获取扶摇行情和财务数据，浏览器只展示可追溯结论；系统不输出综合分、目标价或买卖建议。

## 本地运行

Node.js 18+：

```powershell
$env:FUYAO_API_KEY = '在本机设置，不要写入仓库'
npm test
npm run build
npm run serve
```

打开 `http://127.0.0.1:4173/`。部署环境使用名为 `FUYAO_API_KEY` 的服务端 Secret；浏览器端永远不接触密钥。

## 产品主链路

1. 搜索并消歧任意 A 股公司，再提出一个具体问题。
2. 问题被确定性路由到增长、现金流与负债、估值与同行或合规边界。
3. 先给一句话回答，再展示支持证据、反证、未知项和下一步。
4. 每个结论可以回到价格、财务原表和请求编号；单个上游模块失败时保留未知，不补数。
5. 模糊问题先要求缩小范围；“能买吗、会涨吗”不生成伪预测。

## 架构

- `worker/index.js`：Cloudflare Worker 路由、安全响应头和输入边界。
- `worker/fuyao.js`：扶摇 API 适配器，校验 HTTP 状态与业务 `code === 0`。
- `worker/research.js`：并发聚合、财务对齐与确定性行情计算。
- `ui/`：无框架、响应式研究界面。
- `ui/` 是唯一权威界面来源；`scripts/build-worker.mjs` 同步生成 `dist/` 本地交付物和 Worker 发布物。
- `tests/`：数据适配、聚合、Worker 路由、UI 合同及旧版规则回归测试。
- `docs/superpowers/`：产品设计和实施计划。

## 当前能力边界

- 已接入：A 股搜索、实时行情、日线历史行情、三张财务报表、成长/盈利/偿债/营运/现金流指标。
- 当前公开外部能力未覆盖新闻公告原文、资金流和高频行情，因此这些模块保留为待验证项。
- 财务表按报告期展示累计口径，不把中报累计数伪装成单季度数。
- 阈值仅用于研究提示，不能替代行业比较、会计判断或投资决策。

## 合规

仅供研究辅助和产品演示，不构成投资建议，不提供确定性涨跌预测、目标价或收益承诺。
