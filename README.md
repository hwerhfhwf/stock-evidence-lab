# Stock Evidence Lab

一个面向 A 股研究的 AI Native 个股诊断原型。它不输出“好/坏”总分或买卖建议，而是把结论拆成正面、负面、矛盾和未知四类证据，并允许用户钻取到原始字段、财务期次、计算口径和公开来源。

## 立即运行

项目没有运行时依赖。在仓库根目录执行：

```powershell
python -m http.server 4173 -d dist
```

打开 `http://127.0.0.1:4173/`。

运行测试：

```powershell
node --test
```

## 主链路

1. 输入自然语言研究问题，系统路由到经营增长、现金与资产、估值、行情、行业或事件维度。
2. 确定性规则引擎计算同比、现金覆盖倍数及资产变化，并组合为证据状态。
3. 诊断页同时展示正面、负面、矛盾和未知，不压成单一总分。
4. 点击“查看证据”可核对数值、单位、期次、原始字段和来源链接。
5. 切换“关键缺失 / 接口失败”可验证降级行为。

## 为什么选美的集团

2026 年半年报同时呈现多组真实矛盾：收入和归母净利润仍增长，但扣非净利润下降；经营现金流高于归母净利润，但应收账款较年初显著上升；存货下降，但资产负债率上升。它比单向度案例更能检验产品是否诚实表达复杂证据。

## AI、规则与数据的分工

- **语言模型**：理解问题、选择维度、组织解释、提出待验证问题。
- **确定性引擎**：同比、比率、阈值、证据状态；同一输入必须得到同一结果。
- **数据工具**：获取财务、行情、估值、同行和事件。调用失败时不得让模型补数字。

当前静态原型用公开披露快照替代受限 API。取得扶摇/iFinD 权限后，只需把 `src/data.mjs` 替换成数据适配器输出的同形结构。

## 数据来源与口径

- 主要数据：[美的集团 2026 年半年度报告](https://static.cninfo.com.cn/finalpage/2026-08-28/1225533135.PDF)，财务报告未经审计，原始金额单位为人民币千元；界面换算为亿元。
- 年度基线：[美的集团 2025 年年度报告](https://www.hkexnews.hk/listedco/listconews/sehk/2026/0330/2026033002440_c.pdf)。
- 演示快照时点：2026-08-28。实时行情、同日估值分位和最新事件未接入时显示为“未知”。

## 产品选择与竞品启发

- 借鉴 Koyfin 的多维研究工作区，但不试图覆盖完整行情终端。
- 借鉴 Simply Wall St 的低认知成本概览，但拒绝用单一图形或总分遮蔽矛盾。
- 借鉴 OpenBB 的可替换数据层思想，让公开快照与付费数据源共享同一输出契约。

## 目录

- `dist/`：可直接部署的静态站点。
- `src/engine.mjs`：诊断与路由规则。
- `src/data.mjs`：带来源的真实快照。
- `tests/`：计算、数据追溯和 UI 合同测试。
- `docs/superpowers/`：设计说明与实现计划。

## 已知边界与未做事项

- 未获得扶摇/iFinD 的 API 授权，因此没有伪造实时行情、估值或同行分位。
- 同行比较应按智能家居、楼宇科技、机器人等分部分别选择可比公司，首版仅把它列为待验证问题。
- 自然语言路由使用可审计关键词规则模拟 LLM 工具调用；生产版应使用结构化输出并保留 prompt、模型版本与调用日志。
- 首版仅支持一个标的；多标的需要公司类型识别、指标模板和缓存/限频治理。

## 合规

本项目仅用于研究辅助和产品演示，不构成投资建议，不提供目标价、确定性涨跌预测或收益承诺。
